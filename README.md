# To-do List Dashboard

## About My Project
### I built this web-based To-do_LIst as my B.Tech Full Stack Development assignment to dynamically analyze and display List of tasks. My goal was to create a clean, well manner visualization of Task list that can handle between it proiority and status. 

## Features
- Add new tasks.
- Set task status: Not Started, Running, Completed, or Cancelled.
- Set task priority: Low, Moderate, or High.
- View tasks grouped by status.
- Display total tasks and status-wise counts.
- Responsive design for different screen sizes.

## Functionality
- Add tasks using the Add Task button or Enter key.
- New tasks have default status "Not Started" and priority "Moderate".
- Update task status and priority using dropdown menus.
- Automatically update task boards and counters.
- Display messages when no tasks are available.

## Technologies Used
- HTML
- CSS
- JavaScript
- jQuery
